| Mode | What you enter | Sample size |
|---|---|---|
| **Sample size based on population** | confidence level, error margin, buffer (the proportion is fixed) | computed for each stratum from its population, see *Methods* |
| **Enter sample size** | the target | the number you enter, **applied to each stratum**; no buffer and no design effect |

With **Stratified**, every stratum gets its own target. In the mode "based on population" it depends on the population of the stratum; in "Enter sample size" it is the same number for every stratum.

Changing a parameter does not erase the tables, but **Sample** is disabled until the next Apply, and a new Apply hides the previous sample.
